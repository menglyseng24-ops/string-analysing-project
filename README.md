# Word Analyzing App

# Features
- Allow the user to input a word into the app in which the code will run and return the number of character, consonant, and vowel to the user.
- Looks out for falsy value and punctuation.

# How it works
- The user will be asked to input a word.
- The app will analyze the string and return an error message if the string contains any integer.
- Then the app will first check for vowels then consonant then sum up the number of vowels and consonants for the number of character
- If the user does not enter a string the app will rerun and ask for the user input once again

# Code Example:
- First input the code into your VS code then run the app and input a string
- Lastly the app will return the amount of character, consonants, and vowels.
